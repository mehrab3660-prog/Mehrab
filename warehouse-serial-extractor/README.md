# استخراج سریال مخزن از سامانه

این ابزار برای استخراج «شماره پذیرش»، «نام سازنده» و «سریال مخزن» از سامانه
آزمایش مخازن گاز (مسیرهایی مانند `/TestCenters/GasReception/PrintResult`)
ساخته شده و خروجی را در یک فایل Excel ذخیره می‌کند.

## چرا ورود (Login) خودکار نیست؟

نام کاربری و رمز عبور سامانه شما نباید در هیچ اسکریپت یا مخزن کدی ذخیره شود.
به همین دلیل این ابزار یک مرورگر واقعی باز می‌کند و **شما خودتان** وارد
حساب‌تان می‌شوید، تاریخ را انتخاب می‌کنید و روی «مشاهده نتیجه» کلیک می‌کنید.
از همان لحظه به بعد، تمام کارهای تکراری (خواندن ردیف‌ها، رفتن به صفحه بعد،
ساخت فایل Excel) به‌صورت خودکار انجام می‌شود.

## نصب

```bash
cd warehouse-serial-extractor
pip install -r requirements.txt
playwright install chromium
```

## اجرا

```bash
python extract_serials.py --start-url "https://آدرس-سامانه-شما" --out result.xlsx
```

مراحل:

1. مرورگر باز می‌شود و صفحه ورود سامانه نمایش داده می‌شود.
2. شما به‌صورت دستی وارد حساب کاربری‌تان می‌شوید.
3. به بخش «مشاهده نتیجه» می‌روید، تاریخ موردنظر (مثلاً ۱۴۰۵/۰۱/۰۱) را وارد
   می‌کنید و جستجو را می‌زنید تا صفحه اول نتایج باز شود.
4. به ترمینال برمی‌گردید و Enter را می‌زنید.
5. اسکریپت به‌طور خودکار همه صفحات را طی می‌کند و در پایان فایل
   `result.xlsx` را با ستون‌های زیر می‌سازد:

   | شماره پذیرش | نام سازنده | سریال مخزن |
   |---|---|---|

## اگر «صفحه بعد» پیدا نشد

اسکریپت چند حالت رایج برای دکمه/لینک صفحه بعد را امتحان می‌کند (لیست
`NEXT_PAGE_SELECTORS` در ابتدای `extract_serials.py`). اگر سامانه شما از
ظاهر دیگری استفاده می‌کند، کافی است HTML همان دکمه را باز کرده
(راست‌کلیک → Inspect) و سلکتور مناسب را به همان لیست اضافه کنید.

## نکته امنیتی

این اسکریپت هیچ رمز عبوری را ذخیره یا ارسال نمی‌کند؛ فقط مرورگر را باز
می‌کند و منتظر می‌ماند تا شما خودتان وارد شوید.
