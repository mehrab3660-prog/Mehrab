# استخراج سریال مخزن از سامانه سیمفا (gas.symfa.ir)

این ابزار برای سامانه یکپارچه معاینه فنی خودروهای گازسوز کشور (سیمفا) ساخته
شده و از صفحه «پذیرش‌های گازسوز» و صفحه «چاپ نتایج» هر پذیرش، این موارد را
استخراج می‌کند:

- شماره پذیرش (کد پذیرش / کد پیگیری)
- پلاک خودرو
- نام سازنده مخزن
- سریال مخزن

اگر یک پذیرش چند مخزن داشته باشد (مثلاً خودروی دوگانه‌سوز با دو مخزن)، برای
هر مخزن یک ردیف جداگانه ساخته می‌شود و همان پلاک روی هر دو ردیف تکرار
می‌شود. خروجی نهایی یک فایل Excel با دو شیت جداست: «تک مخزن» و «جفت مخزن».

## چرا ورود (Login) خودکار نیست؟

نام کاربری و رمز عبور سامانه شما نباید در هیچ اسکریپت یا مخزن کدی ذخیره شود.
به همین دلیل این ابزار یک مرورگر واقعی باز می‌کند و **شما خودتان** وارد
حساب‌تان می‌شوید. از همان لحظه به بعد، تمام کارهای تکراری (باز کردن صفحه
نتیجه هر پذیرش، رفتن به صفحه بعد، ساخت فایل Excel) به‌صورت خودکار انجام
می‌شود.

## نصب

```bash
cd warehouse-serial-extractor
pip install -r requirements.txt
playwright install chromium
```

## اجرا

```bash
python extract_serials.py --out result.xlsx
```

مراحل:

1. مرورگر باز می‌شود و صفحه «پذیرش‌های گازسوز» (`gas.symfa.ir/TestCenters/GasReception`) نمایش داده می‌شود.
2. شما به‌صورت دستی وارد حساب کاربری‌تان می‌شوید (اگر از قبل وارد نشده باشید).
3. بازه تاریخ («از تاریخ» / «تا تاریخ») موردنظر را وارد می‌کنید و روی
   «جستجو» می‌زنید تا صفحه اول لیست پذیرش‌ها باز شود.
4. به ترمینال برمی‌گردید و Enter را می‌زنید.
5. اسکریپت برای هر ردیفی که دکمه «چاپ نتایج» دارد (یعنی نتیجه ثبت شده)،
   صفحه نتیجه همان پذیرش را می‌خواند و اطلاعات مخزن(ها) را استخراج می‌کند.
   پذیرش‌های بدون نتیجه (بدون دکمه «چاپ نتایج») نادیده گرفته می‌شوند.
6. روی شماره صفحه بعدی (۲، ۳، ...) کلیک می‌کند و تا آخرین صفحه ادامه می‌دهد.
7. در پایان فایل `result.xlsx` ساخته می‌شود که دو شیت دارد:
   - شیت «تک مخزن»: پذیرش‌هایی که فقط یک مخزن دارند.
   - شیت «جفت مخزن»: پذیرش‌هایی که دو مخزن دارند (برای هر مخزن یک ردیف، با پلاک تکراری).

   هر دو شیت این ستون‌ها را دارند:

   | شماره پذیرش | پلاک | نام سازنده | سریال مخزن |
   |---|---|---|---|

## اگر شماره صفحه بعد پیدا نشد

اسکریپت به‌دنبال لینک/دکمه‌ای با متن دقیق شماره صفحه بعدی (مثلاً «۲») در
پایین لیست پذیرش‌ها می‌گردد. اگر ساختار صفحه‌بندی سایت تغییر کرده و پیدا
نشد، HTML همان نوار صفحه‌بندی (راست‌کلیک → Inspect) را بفرستید تا تابع
`click_page_number` در `extract_serials.py` به‌روزرسانی شود.

## نکته امنیتی

این اسکریپت هیچ رمز عبوری را ذخیره یا ارسال نمی‌کند؛ فقط مرورگر را باز
می‌کند و منتظر می‌ماند تا شما خودتان وارد شوید و جستجو را انجام دهید.
