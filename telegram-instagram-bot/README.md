# ربات تلگرامی دانلود ویدیو

کاربر لینک اینستاگرام (پست/ریل/IGTV)، تیک‌تاک، یوتیوب شورتس یا توییتر/X رو
برای ربات می‌فرسته، ربات ویدیو رو دانلود می‌کنه و همراه با دکمه‌های شیشه‌ای
(inline keyboard) زیرش برمی‌گردونه:

- **📝 کپشن** — کپشن اصلی پست رو به صورت پیام متنی می‌فرسته.
- **🌐 ترجمه کپشن** — کپشن رو به فارسی ترجمه می‌کنه (با Google Translate، بدون نیاز به کلید API).
- **🎵 صدا** — فقط صدای ویدیو رو به‌صورت پیام صوتی (voice) استخراج و ارسال می‌کنه.
- **🎞 GIF** — یک GIF کوتاه (۶ ثانیه‌ی اول) از ویدیو می‌سازه و می‌فرسته.
- **✂️ برش** — ازت بازه‌ی زمانی رو می‌پرسه (مثلاً `5-15`) و همون تکه از ویدیو رو برات می‌بره و می‌فرسته.

اگه لینک به یک پست عکسی (نه ویدیویی) اشاره کنه، ربات عکس رو می‌فرسته
(فقط با دکمه‌ی کپشن، چون صدا/GIF برای عکس معنی نداره).

لینک‌های تکراری از کش محلی سرو می‌شن (نیازی به دانلود دوباره نیست) و اگه
ویدیو بزرگ‌تر از حد مجاز تلگرام (۵۰ مگابایت) باشه، خودکار فشرده می‌شه.

## پنل ادمین (بدون دستور، فقط دکمه)

هیچ دستوری برای مدیریت لازم نیست. وقتی ادمین (کسی که آیدی عددیش در
`ADMIN_ID` تنظیم شده) به ربات `/start` می‌زنه، یک کیبورد ثابت با دکمه‌ی
«⚙️ تنظیمات» پایین چتش ظاهر می‌شه که همیشه در دسترسه. با زدنش این
گزینه‌ها میان (به‌صورت دکمه‌ی شیشه‌ای):

- **📜 دانلودهای من** — تاریخچه‌ی خودت.
- **📊 آمار** — تعداد کل کاربران ربات.
- **👥 کاربران** — لیست کاربرا؛ با زدن روی اسم هرکدوم، پیام‌هایی که
  فرستاده (لینک‌هاش) نشون داده می‌شه.
- **📢 پیام همگانی** — می‌زنی، ربات ازت متن پیام رو می‌خواد، همون پیام
  بعدی که بفرستی برای همه‌ی کاربرای ثبت‌شده ارسال می‌شه.

این منو و همه‌ی زیرمجموعه‌هاش فقط برای ادمین قابل دیدن و استفاده‌ست؛
کاربرای دیگه اصلاً دکمه یا گزینه‌ای برای مدیریت نمی‌بینن.

علاوه بر این، هر پیامی که هر کاربری به ربات بفرسته (لینک، متن یا استیکر)
بلافاصله یک نسخه‌ش برای ادمین هم فوروارد می‌شه، همراه با اسم/یوزرنیم/آیدی
فرستنده. **برای پاسخ‌دادن به اون کاربر، ادمین کافیه روی همون پیام
فورواردشده Reply بزنه و متنش رو بنویسه** — ربات خودش پیام رو مستقیم برای
همون کاربر می‌فرسته، بدون اینکه کاربر بفهمه از طرف ادمینه یا ربات.

کاربران عادی روزی حداکثر ۲۰ دانلود می‌تونن انجام بدن (قابل تغییر با ثابت
`RATE_LIMIT_PER_DAY` در `bot.py`)؛ ادمین هیچ محدودیتی نداره.

## پیش‌نیازها

- Python 3.10+
- [ffmpeg](https://ffmpeg.org/) نصب‌شده روی سیستم و در دسترس در `PATH`
  (برای استخراج صدا، GIF و فشرده‌سازی ویدیو لازم است):
  ```bash
  sudo apt-get install ffmpeg
  ```
- یک توکن ربات تلگرام از [@BotFather](https://t.me/BotFather)

## نصب و اجرا

```bash
cd telegram-instagram-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# سپس BOT_TOKEN و ADMIN_ID را داخل فایل .env قرار دهید
# ADMIN_ID را می‌توانید با پیام‌دادن به @userinfobot در تلگرام پیدا کنید

python3 bot.py
```

## اجرای دائمی با systemd

برای اینکه ربات بعد از بستن SSH یا ری‌استارت سرور هم روشن بمونه، فایل
`ig-bot.service` همراه پروژه هست. `REPLACE_WITH_YOUR_USERNAME` و
`REPLACE_WITH_ABSOLUTE_PATH` رو با مقادیر واقعی سرورت جایگزین کن (مسیر رو
با `pwd` تو همین پوشه پیدا می‌کنی)، سپس:

```bash
sudo cp ig-bot.service /etc/systemd/system/
sudo nano /etc/systemd/system/ig-bot.service   # مقادیر REPLACE_WITH_... رو عوض کن
sudo systemctl daemon-reload
sudo systemctl enable ig-bot
sudo systemctl start ig-bot
sudo systemctl status ig-bot
```

برای دیدن لاگ‌های زنده:
```bash
journalctl -u ig-bot -f
```

## نکات

- دانلود به‌وسیله‌ی [yt-dlp](https://github.com/yt-dlp/yt-dlp) انجام می‌شود.
  برای محتوای عمومی نیازی به لاگین نیست؛ برای محتوای خصوصی می‌توانید مسیر
  یک فایل کوکی (فرمت Netscape) را در متغیر محیطی `COOKIES_FILE` بدهید.
- فایل‌های دانلودشده در پوشه‌ی موقت سیستم (`ig_bot_downloads`) نگه داشته
  می‌شوند تا لینک‌های تکراری از کش سرو شوند، ولی هر ساعت یک پاکسازی
  خودکار داخل خود ربات اجرا می‌شه و فایل‌های قدیمی‌تر از ۲۴ ساعت
  (قابل تغییر با `CLEANUP_MAX_AGE_HOURS` در `bot.py`) رو پاک می‌کنه.
- برای استفاده از ربات داخل گروه‌ها، باید از طریق @BotFather با دستور
  `/setprivacy` روی `Disable` بذارید تا ربات بتونه پیام‌های گروه رو ببینه.
- برای فعال کردن حالت inline (استفاده از `@نام_ربات لینک` در هر چتی)، باید
  از طریق @BotFather با دستور `/setinline` این قابلیت رو فعال کنید (این
  نسخه از ربات هنوز handler اینلاین نداره؛ در صورت نیاز اضافه می‌شود).

## ایده‌هایی که عمداً نساختیم

- **تشخیص آهنگ ریل و پروکسی ضد بلاک** — نیاز به سرویس/کلید API پولی
  (مثل ACRCloud یا AudD) دارن که فعلاً نداریم.
- **پنل ادمین تحت وب** — یک اپ جدا و بزرگه (هاستینگ، احراز هویت و...)؛
  اگه لازم شد جدا می‌سازیمش.
- **انتخاب کیفیت ویدیو قبل از دانلود** — با طراحی فعلی (کش خودکار بر
  اساس لینک) هم‌خونی نداره؛ هر لینک یک نسخه‌ی کش‌شده داره.
- **پست خودکار به یک کانال تلگرامی** — قابل‌ساختنه، فقط نیاز به آیدی
  کانال مقصد داره؛ بگو کدوم کانال تا اضافه‌ش کنیم.
- **اتصال به n8n** — طبق درخواست، عمداً کنار گذاشته شد.
