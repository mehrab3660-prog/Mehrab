# ربات تلگرامی دانلود کلیپ اینستاگرام

لینک ریلز یا پست اینستاگرام رو براش می‌فرستی، ربات کلیپ، صدا و کپشنش رو آماده می‌کنه
و یک دکمه‌ی «ارسال کن ✅» زیرش می‌ذاره؛ فقط وقتی خودت روی اون دکمه بزنی، فایل‌ها برات
فرستاده می‌شن (تا وقتی نزنی، چیزی ارسال نمی‌شه).

## پیش‌نیازها

- پایتون ۳.10 به بالا
- `ffmpeg` نصب روی سیستم (برای جدا کردن صدا از ویدیو)
  - اوبونتو/دبیان: `sudo apt install ffmpeg`
  - مک: `brew install ffmpeg`

## نصب

```bash
cd telegram-instagram-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## تنظیم `.env`

1. با @BotFather توی تلگرام یک ربات جدید بساز و توکنش رو بگیر، بذارش جلوی `BOT_TOKEN`.
2. ربات رو یک بار اجرا کن، توی چت با ربات دستور `/whoami` رو بزن تا آیدی عددی خودت رو
   بگیری، و آن را جلوی `ALLOWED_USER_IDS` بذار (اگر چند نفر باید دسترسی داشته باشن،
   آیدی‌ها رو با کاما جدا کن). اگر این مقدار رو خالی بذاری، ربات برای هرکسی که پیام
   بده کار می‌کنه — برای اینکه ربات فقط مخصوص خودت بمونه حتما پرش کن.
3. اگر پست‌های خصوصی یا محدودشده هم می‌خوای دانلود کنی، باید فایل کوکی مرورگرت
   (export شده با یک اکستنشن مثل «Get cookies.txt») رو کنار پروژه بذاری و مسیرش رو
   جلوی `INSTAGRAM_COOKIES_FILE` بنویسی.

## اجرا

```bash
python bot.py
```

## نحوه استفاده

1. لینک ریلز/پست اینستاگرام رو توی چت ربات بفرست.
2. ربات پیام «در حال دریافت...» می‌ده و بعد از آماده شدن فایل‌ها، دکمه‌ی
   «ارسال کن ✅» و «لغو ❌» نشونت می‌ده.
3. با زدن «ارسال کن» ویدیو، فایل صوتی (mp3) و کپشن پست برات فرستاده می‌شه.

## محدودیت‌ها

- سقف حجم فایلی که یک ربات تلگرام می‌تونه آپلود کنه ۵۰ مگابایته؛ کلیپ‌های خیلی
  حجیم ممکنه ارسال نشن (پیام خطا می‌گیری).
- دانلود پست‌های خصوصی/محدود بدون کوکی معتبر ممکن نیست.

## اجرا با Docker (اختیاری)

```bash
docker build -t ig-clip-bot .

```
