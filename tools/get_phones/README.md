# استخراج اطلاعات پذیرش (get_phones)

ابزاری برای استخراج خودکار شماره تلفن، تاریخ ثبت/انقضا و پلاک از سامانه
`petrol.symfa.ir` بر اساس فهرستی از «کد پذیرش»‌ها.

## دانلود نسخه آماده (بدون نیاز به نصب پایتون)

هر بار که تغییری در این پوشه push شود، گیت‌هاب اکشن به‌صورت خودکار یک فایل
اجرایی تک‌فایلی (`get_phones.exe`) برای ویندوز می‌سازد و آن را به‌عنوان
Release در ریپازیتوری منتشر می‌کند. کافی‌ست از بخش **Releases** ریپازیتوری،
آخرین نسخه با تگ `get-phones-v*` را باز کرده و `get_phones.exe` را دانلود
کنید. برای اجرا فقط باید **Firefox** روی سیستم نصب باشد؛ چیز دیگری لازم
نیست (geckodriver به‌صورت خودکار توسط خود برنامه مدیریت می‌شود).

## اجرا از روی سورس (اختیاری)

```
pip install -r requirements.txt
python get_phones.py
```

## نحوه استفاده

1. نام‌کاربری و رمز عبور سامانه را وارد کنید.
2. تعداد مرورگرهای هم‌زمان (پیش‌فرض ۴) و حالت Headless را تنظیم کنید.
3. فایل اکسل کدهای پذیرش (ستون اول، بدون هدر) را انتخاب کنید.
4. «شروع» را بزنید؛ پیشرفت و لاگ زنده نمایش داده می‌شود.
5. در پایان (یا با زدن «توقف»)، مسیر ذخیره فایل خروجی اکسل را انتخاب کنید.
