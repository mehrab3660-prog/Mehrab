# سیستم پذیرش دستگاه (مستقل و سبک)

یک برنامه‌ی کاملاً جدا و سبک، فقط برای ثبت و پیگیری **پذیرش** موبایل/تبلت — بدون نیاز به تعریف کالا، دسته‌بندی، انبار یا هر چیز دیگری از حسابداری. همین الان قابل استفاده است.

اگر بعداً به حسابداری، انبار قطعات، تخصیص تعمیرکار، گارانتی و فاکتور هم نیاز پیدا کردی، نسخه‌ی کامل‌تر در پوشه‌ی `accounting-app` (تب «تعمیرات موبایل») همین قابلیت‌ها را دارد.

## اجرا

```
cd reception-app
pip install -r requirements.txt
python app.py
```

همین! سرور محلی بالا می‌آید و مرورگر پیش‌فرضت خودکار باز می‌شود. رمز عبور اولیه به‌صورت تصادفی ساخته می‌شود و در فایل `FIRST_LOGIN_PASSWORD.txt` (کنار برنامه) و در کنسول نمایش داده می‌شود؛ آن را از همان‌جا بردار و پس از ورود، از «تنظیمات» تغییرش بده.

## ساخت exe مستقل (دابل‌کلیک و اجرا)

روی فایل `build_exe.bat` دو بار کلیک کن. فایل نهایی در `dist\ReceptionApp.exe` ساخته می‌شود. بعد از اجرای اول، کنار همان exe یک فایل `reception.db` (دیتابیس) ساخته می‌شود — این را جابه‌جا یا پاک نکن.

## امکانات

- پذیرش دستگاه با شماره پیگیری خودکار (مثل P-00001): مشتری، تلفن، برند/مدل/رنگ، IMEI، رمز دستگاه، وضعیت ظاهری، لوازم همراه، مشکل اعلام‌شده، تاریخ تحویل احتمالی، پیش‌پرداخت
- لیست دستگاه‌ها با جستجوی سریع (شماره پذیرش، IMEI، نام/تلفن مشتری، مدل) و فیلتر وضعیت
- گردش وضعیت ساده: پذیرش‌شده → در حال بررسی/تعمیر → آماده تحویل → تحویل‌شده (+ لغو‌شده)
- چاپ رسید پذیرش آماده برای مشتری
- تنظیمات: نام/تلفن/آدرس مغازه (روی رسید چاپی نمایش داده می‌شود)، تغییر رمز عبور
- بکاپ‌گیری دستی و دانلود فایل دیتابیس

## نکته امنیتی

فایل `reception.db` حاوی اطلاعات مشتریان (تلفن، رمز دستگاه) است. هر چند وقت یک‌بار از این فایل یک نسخه پشتیبان بگیر (از «تنظیمات» یا مستقیم از پوشه‌ی کنار exe).
