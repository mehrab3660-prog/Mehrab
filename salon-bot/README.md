# 💇‍♀️ ربات نوبت‌دهی آرایشگاه زنانه (تلگرام)

رباتی برای رزرو آنلاین نوبت سالن‌های زیبایی — با پنل مشتری، پنل مدیر آرایشگاه و پنل مدیر کل (چند آرایشگاه روی یک ربات، با سیستم اشتراک).

## امکانات

**👩 مشتری**
- 📅 رزرو نوبت: انتخاب خدمت ← روز (تقویم شمسی، روزهای «تعطیل» و «تکمیل» مشخص) ← ساعت خالی
- دریافت شماره موبایل با یک دکمه و ثبت نام
- 💳 پرداخت بیعانه کارت‌به‌کارت و ارسال عکس رسید (اگر آرایشگاه فعال کرده باشد)
- 📋 نوبت‌های من: مشاهده وضعیت، لغو نوبت، ارسال رسید
- ⏰ پیام یادآوری قبل از نوبت
- ورود مستقیم با لینک اختصاصی هر آرایشگاه (`t.me/<bot>?start=s1`)

**🛠 پنل مدیریت آرایشگاه**
- 📋 نوبت‌های رزروشده (امروز / فردا / همه / منتظر تایید) + تایید، رد، لغو، «انجام شد»، مشاهده رسید
- ✂️ مدیریت خدمات (نام، قیمت، مدت، فعال/غیرفعال، حذف)
- 🗓 روزها و ساعات کاری هر روز هفته، فاصله نوبت‌ها، تعطیلات خاص
- 🏪 مشخصات آرایشگاه (نام، مدیر، آدرس، تلفن)
- 💳 بیعانه و کارت‌به‌کارت
- ⏰ تنظیم یادآوری (خاموش، ۱ تا ۲۴ ساعت قبل)
- 💬 پیام خوش‌آمدگویی مشتری
- ⭐️ اشتراک من (مشاهده و تمدید با ارسال رسید)
- 🔗 لینک رزرو من

**🛡 پنل مدیر کل**
- 📊 آمار سامانه
- 🏪 مدیریت آرایشگرها (افزودن، تمدید اشتراک، فعال/مسدود، تغییر مالک)
- 🧾 رسیدهای اشتراک (تایید/رد) و 📚 تاریخچه پرداخت
- ⚙️ تنظیمات پرداخت (مبلغ، مدت، شماره کارت)
- 📢 پیام همگانی

## نصب روی سرور (کنار ربات‌های دیگر، بدون تداخل)
فایل `salon-bot.zip` را روی سرور بفرستید (مثلاً با WinSCP به `/root`) و:
```bash
apt install -y unzip python3-venv
cd /root && unzip salon-bot.zip
cd salon-bot && sudo bash install.sh
```
اسکریپت ربات را در پوشه جدای `/opt/salon-bot` با محیط پایتون جدا (venv) و سرویس جدا به نام `salon-bot` نصب می‌کند
و توکن و شناسه مدیر را می‌پرسد. به پوشه، کتابخانه‌ها یا سرویس ربات‌های دیگر دست نمی‌زند.
توکن باید مال ربات جدید باشد، نه ربات قبلی.

## راه‌اندازی دستی

۱. در تلگرام به [@BotFather](https://t.me/BotFather) برو، `/newbot` بزن و توکن را بگیر.

۲. نصب:
```bash
cd salon-bot
pip install -r requirements.txt
cp .env.example .env
```

۳. فایل `.env` را باز کن و `BOT_TOKEN` را بگذار. اگر شناسه عددی‌ات را نمی‌دانی، اول ربات را اجرا کن و دستور `/id` را بفرست، بعد آن را در `SUPER_ADMIN_IDS` بنویس و ربات را دوباره اجرا کن.
اگر سرور در ایران است، `PROXY_URL` را تنظیم کن (مثلاً `socks5://127.0.0.1:1080`).

۴. اجرا:
```bash
python run.py
```

## شروع کار
1. مدیر کل: «🛡 پنل مدیر کل ← 🏪 مدیریت آرایشگرها ← ➕ افزودن آرایشگاه» و وارد کردن شناسه عددی صاحب آرایشگاه (او با `/id` شناسه‌اش را می‌بیند).
2. صاحب آرایشگاه: `/start` ← «🛠 پنل مدیریت» ← خدمات و ساعات کاری را تنظیم کند و «🔗 لینک رزرو من» را برای مشتری‌ها بفرستد.
3. مشتری‌ها از لینک وارد می‌شوند و نوبت می‌گیرند.

## نکات
- اطلاعات در فایل SQLite (`salon.db`) ذخیره می‌شود؛ از آن بکاپ بگیرید.
- هر آرایشگاه در هر لحظه یک نوبت می‌پذیرد (یک صندلی/آرایشگر).
- نوبتی که بیعانه‌اش تا ۳۰ دقیقه پرداخت نشود خودکار آزاد می‌شود (`PAYMENT_TIMEOUT_MIN`).
- سایر تنظیمات اختیاری `.env`: `BOOKING_DAYS` (چند روز آینده قابل رزرو، پیش‌فرض ۷)، `MIN_LEAD_MIN`، `TRIAL_DAYS`.
