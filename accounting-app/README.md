# سیستم حسابداری مغازه لوازم الکتریکی

## 🆕 نسخه جدید: رابط کاربری وب مدرن (توصیه‌شده)
رابط کاربری کاملاً بازطراحی شد — دیگر Tkinter نیست، یک صفحه وب مدرن با ظاهری شبیه Notion / Linear / Microsoft 365 است که در مرورگر خودت باز می‌شود (کاملاً آفلاین و محلی، بدون نیاز به اینترنت).

**اجرا:**
```
cd client
pip install -r requirements.txt
python run_app.py
```
همین! سرور محلی خودش پشت‌صحنه بالا می‌آید و مرورگر پیش‌فرضت خودکار باز می‌شود. نام کاربری: `admin` — رمز عبور اولیه به‌صورت تصادفی ساخته می‌شود و در فایل `FIRST_LOGIN_ADMIN_PASSWORD.txt` (کنار برنامه) و همچنین در کنسول نمایش داده می‌شود؛ آن را از همان‌جا بردار و پس از اولین ورود، از بخش «تنظیمات کلی › کاربران» تغییرش بده.

**ساخت exe مستقل (دابل‌کلیک و اجرا):**

**روش ساده (توصیه‌شده):** فقط روی فایل `client\build_exe.bat` دو بار کلیک کن. خودش همه‌چیز (نصب نیازمندی‌ها + ساخت exe) رو انجام می‌ده و در آخر می‌گه فایل کجاست.

**یا دستی:**
```
pip install pyinstaller
pyinstaller --onefile --name AccountingApp --icon=assets/icon.ico --add-data "web;web" --add-data "assets;assets" --add-data "fonts;fonts" run_app.py
```
فایل نهایی: `client\dist\AccountingApp.exe`

> **نکته مهم:** بعد از ساخته‌شدن exe، فایل `AccountingApp.exe` را از پوشه `dist` بردار و هرجا خواستی (مثلاً دسکتاپ یا `C:\Accounting`) کپی کن. از همون لحظه که اولین بار اجرا و باهاش کار کنی، کنار همون فایل exe به‌طور خودکار این‌ها ساخته می‌شوند: `accounting.db` (دیتابیس اصلی)، پوشه `backups`، پوشه `assets` (لوگو)، و در صورت نیاز `config.json`. **این‌ها را جابه‌جا یا پاک نکن** — همیشه با خودِ exe کنار هم بمونن، وگرنه اطلاعاتت رو از دست می‌دی. اگر فایل `Vazir.ttf` یا `config.json` می‌خوای اضافه کنی، اون‌ها رو هم توی همون پوشه‌ی کنار exe (نه پوشه client اصلی) بذار.

### روند آپدیت در آینده
هر وقت خواستی چیزی توی برنامه عوض/اضافه بشه:
1. فایل‌های جدید (زیپ) رو جایگزین پوشه‌ی سورس (`client/`) کن.
2. روی `build_exe.bat` دو بار کلیک کن تا exe جدید ساخته بشه.
3. فایل `dist\AccountingApp.exe` جدید رو به‌جای فایل exe قدیمی‌ات (همون‌جایی که روی دسکتاپ یا هرجا نگه داشتی) کپی کن.

چون دیتابیس و تنظیماتت کنار خودِ exe (نه داخلش) ذخیره می‌شه، با این جایگزینی **هیچ اطلاعاتی از دست نمی‌ره** — فقط برنامه آپدیت می‌شه.

### ویژگی‌های طراحی جدید
- منوی عمودی سمت راست با آیکون، مطابق جهت فارسی (RTL)
- داشبورد با کارت‌های آماری بزرگ (فروش، سود، صندوق، طلب) + نمودار سود ماهانه
- نوار جستجوی سریع بالای صفحه (فیلتر آنی روی جدول صفحه فعلی)
- حالت روشن/تیره با یک کلیک (رنگ‌بندی: پس‌زمینه روشن، آبی تیره اصلی، سبز تأکیدی، نارنجی/قرمز برای هشدارها)
- همه صفحات (کالاها، فاکتور فروش/خرید، تاریخچه، مشتریان، چک‌ها، صندوق، گزارش‌ها، پشتیبان‌گیری، کاربران، لاگ) در همین یک صفحه با تعویض آنی، بدون تأخیر یا لود مجدد
- واکنش‌گرا: روی صفحه‌های کوچک‌تر هم قابل استفاده است (منو جمع می‌شود)
- چون خودِ همین صفحه یک وب‌اپ است، اگر بعداً به نسخه تحت‌شبکه (پوشه `server`) نیاز پیدا کردی، دقیقاً همین ظاهر از هر مرورگری در شبکه هم قابل‌دسترسی خواهد بود — نیازی به نصب برنامه جداگانه روی هر کامپیوتر نیست، کافی است آدرس سرور را در مرورگر باز کنند.

### درباره چاپ فاکتور (نسخه جدید، دقیقاً مثل فرم‌های رسمی فارسی)
دکمه چاپ فاکتور دیگر PDF نمی‌سازد — یک **صفحه HTML آماده چاپ** در تب جدید مرورگر باز می‌کند که دقیقاً شبیه فرم‌های رسمی فارسی حسابداری است: نام و تلفن و آدرس مغازه بالای صفحه، شماره و تاریخ فاکتور، نام خریدار/فروشنده، جدول کالاها (ردیف، نوع کالا، شرح کالا، تعداد، مبلغ واحد، جمع کل)، جمع کل و تخفیف و مانده حساب، **مبلغ به حروف**، و در پایین جای امضای خریدار و فروشنده.

**چرا این روش عوض شد:** روش قبلی (ساخت PDF با کتابخانه پایتون) بدون نصب یک فونت فارسی جداگانه نمی‌توانست حروف فارسی را درست بچسباند. روش جدید از خودِ مرورگر برای رندر و چاپ استفاده می‌کند، پس فارسی همیشه با فونت خودِ ویندوز (Tahoma و مشابه) کاملاً درست و خوانا چاپ می‌شود — نیازی به هیچ فونت اضافه‌ای نیست.

روی صفحه‌ی باز شده، دکمه «چاپ این فاکتور» را بزن (یا Ctrl+P) و چاپگر موردنظر (معمولی، A4/A5، یا حرارتی) را انتخاب کن.

**برای تنظیم نام/تلفن/آدرس مغازه روی فاکتور:** فایل `client/config.example.json` را کپی کن به `client/config.json` و بخش `"shop"` را با اطلاعات واقعی مغازه‌ات پر کن:
```json
"shop": {
  "name": "فروشگاه لوازم الکتریکی رضایی",
  "phones": "021-33334567 - 09123456789",
  "address": "خیابان سردار، جنب بانک مسکن"
}
```
اگر این تنظیم را نکنی، یک نام پیش‌فرض نمایش داده می‌شود.

> نکته: تاریخ فاکتور به تقویم میلادی نمایش داده می‌شود (نه شمسی)، چون تبدیل به تقویم شمسی نیاز به یک کتابخانه اضافه دارد که باید جداگانه تست شود. اگر تقویم شمسی برایت مهم است، بگو تا در مرحله بعد اضافه‌اش کنم.

### درباره روش قدیمی PDF (هنوز موجود، ولی دیگر توصیه نمی‌شود)
Endpoint قدیمی PDF (`/invoices/<id>/pdf`) هنوز در کد هست و کار می‌کند، اما چون رندر فارسی‌اش به فونت Vazir وابسته است (که باید دستی دانلود و در پوشه `fonts` گذاشته شود)، دیگر روش پیش‌فرض چاپ نیست.

### نکته درباره نسخه‌های قبلی Tkinter
فایل‌های `client.py` و `standalone_app.py` (نسخه قدیمی‌تر با رابط Tkinter) هنوز در پروژه هستند و کار می‌کنند، اما دیگر به‌روزرسانی بصری نمی‌شوند — از این به بعد `run_app.py` (رابط وب) نسخه‌ی اصلی و توصیه‌شده است.

## مرحله ۱: آماده‌سازی روی کامپیوتر سرور

1. پایتون نسخه ۳.۱۰ به بالا را از [python.org](https://www.python.org/downloads/) نصب کنید (هنگام نصب تیک "Add to PATH" را بزنید).
2. پوشه `server` را در جایی مثل `C:\Accounting\server` قرار دهید.
3. Command Prompt را باز کنید و اجرا کنید:
```
cd C:\Accounting\server
pip install -r requirements.txt
python server.py
```
4. اگر پیام "سرور حسابداری در حال اجراست" را دیدید یعنی سرور روشن است. این پنجره را باز نگه دارید (می‌توانید مینیمایزش کنید).
5. آی‌پی این کامپیوتر را پیدا کنید: در Command Prompt بنویسید `ipconfig` و مقابل "IPv4 Address" چیزی مثل `192.168.1.10` را یادداشت کنید.

> نکته: در ویندوز فایروال ممکن است یک‌بار اجازه دسترسی به شبکه بخواهد؛ گزینه "Allow access" را بزنید.

## مرحله ۲: نصب کلاینت روی هر کامپیوتر (سرور و بقیه سیستم‌ها)

1. همان‌طور که بالا گفته شد، پایتون را نصب کنید.
2. پوشه `client` را روی هر کامپیوتر کپی کنید.
3. اجرا کنید:
```
cd client
pip install -r requirements.txt
python client.py
```
4. در صفحه ورود، آدرس سرور را وارد کنید:
```
http://192.168.1.10:5050
```
(به‌جای `192.168.1.10` همان آی‌پی کامپیوتر سرور از مرحله قبل را بگذارید. روی خود کامپیوتر سرور می‌توانید `http://127.0.0.1:5050` بگذارید.)
5. نام کاربری: `admin` — رمز عبور اولیه در فایل `FIRST_LOGIN_ADMIN_PASSWORD.txt` کنار سرور (و در کنسول سرور) نوشته شده؛ حتماً بعد از ورود اول از بخش «مدیریت کاربران» تغییرش بده.

## مرحله ۳: تبدیل به یک فایل exe مستقل (بدون نیاز به نصب پایتون روی هر سیستم)

بعد از اینکه مطمئن شدید همه‌چیز درست کار می‌کند، این دستورات را **روی خود ویندوز** اجرا کنید تا فایل exe واقعی ساخته شود:

### ساخت exe سرور:
```
cd server
pip install pyinstaller
pyinstaller --onefile --name AccountingServer server.py
```
فایل نهایی در `server\dist\AccountingServer.exe` ساخته می‌شود.

### ساخت exe کلاینت (با آیکون اختصاصی):
```
cd client
pip install pyinstaller
pyinstaller --onefile --windowed --name AccountingClient --icon=assets/icon.ico client.py
```
فایل نهایی در `client\dist\AccountingClient.exe` ساخته می‌شود؛ این‌بار با آیکون اختصاصی مغازه به‌جای آیکون پیش‌فرض پایتون.

بعد از این مرحله، فقط کافیست فایل‌های exe را کپی و اجرا کنید؛ دیگر نیازی به نصب پایتون یا اجرای دستورات نیست.

> چرا این کار را خودتان روی ویندوز انجام می‌دهید بهتر است؟ چون exe باید دقیقاً روی همان نوع ویندوزی که قرار است اجرا شود ساخته شود تا صد‌درصد سازگار باشد.

## امکانات فعلی
- مدیریت کالا (کد، نام، واحد، قیمت خرید/فروش، موجودی، حداقل موجودی)
- فاکتور فروش و خرید با کسر/افزایش خودکار موجودی انبار
- مدیریت مشتریان و تامین‌کنندگان با مانده حساب (بدهکار/بستانکار)
- ثبت نسیه و به‌روزرسانی خودکار بدهی مشتری
- **مدیریت چک‌ها:** ثبت خودکار چک هنگام صدور فاکتور با نوع پرداخت "check"، پیگیری سررسید،
  علامت‌گذاری وصول‌شده (که خودش خودکار به صندوق اضافه می‌شود) یا برگشتی
- **چاپ فاکتور PDF:** بعد از هر فاکتور و همچنین از تب "تاریخچه و چاپ فاکتورها" می‌توانید هر فاکتور
  قدیمی را انتخاب و PDF آن را بسازید و چاپ/ذخیره کنید
- **پشتیبان‌گیری خودکار روزانه:** سرور هر روز یک نسخه از دیتابیس را در پوشه `server/backups`
  ذخیره می‌کند؛ از تب "پشتیبان‌گیری" هم می‌توانید هر لحظه دستی نسخه پشتیبان بگیرید
- صندوق (ثبت دریافت/پرداخت نقدی و موجودی لحظه‌ای)
- گزارش خلاصه: مجموع فروش، خرید، سود تقریبی، طلب از مشتریان، هشدار کالاهای رو به اتمام
- **گزارش ماهانه با نمودار:** تب "گزارش ماهانه" فروش، خرید و سود/زیان هر ماه را به‌صورت جدول و نمودار میله‌ای نشان می‌دهد
- **چند کاربر با سطح دسترسی:** دو نقش داریم — `admin` (مدیر) و `employee` (کارمند). تب‌های "پشتیبان‌گیری" و "مدیریت کاربران" فقط برای مدیر نمایش داده می‌شود؛ از تب "مدیریت کاربران" می‌توانید برای کارمندهای مغازه حساب کاربری جدا بسازید
- **آیکون اختصاصی:** یک آیکون ساده و اختصاصی (`client/assets/icon.ico`) برای برنامه ساخته شده که هنگام تبدیل به exe جایگزین آیکون پیش‌فرض پایتون می‌شود
- **دسته‌بندی کالا:** از تب "کالاها" می‌توانید دسته‌های دلخواه (روشنایی، سیم و کابل، تابلو برق و...) بسازید و هر کالا را به یک دسته وصل کنید
- **تسویه حساب:** از تب "مشتریان و تامین‌کنندگان"، دکمه "ثبت تسویه حساب" برای وقتی است که مشتری نسیه‌اش را نقد می‌دهد یا شما به تامین‌کننده بدهی می‌پردازید — مانده حساب و صندوق خودکار به‌روزرسانی می‌شود
- **ریز حساب مشتری:** دکمه "مشاهده ریز حساب" همه فاکتورهای یک طرف‌حساب و مانده فعلی‌اش را در یک پنجره جدا نشان می‌دهد

## گزارش شبانه: خلاصه فروش به ایمیل + آپلود بکاپ به VPS

هر شب ساعت ۲۳ (۱۱ شب)، اگر سرور روشن باشد، این دو کار خودکار انجام می‌شود:
1. یک ایمیل حاوی خلاصه فروش امروز (تعداد فاکتور، جمع فروش، موجودی صندوق، پرفروش‌ترین کالاها، هشدار کالای رو به اتمام) به آدرس جیمیلت فرستاده می‌شود.
2. آخرین نسخه پشتیبان دیتابیس از طریق SSH به VPS شما آپلود می‌شود.

### مرحله ۱: ساخت App Password جیمیل (چون جیمیل رمز عادی حساب را برای برنامه‌ها قبول نمی‌کند)
1. وارد حساب گوگل شو → Security → مطمئن شو "2-Step Verification" روشن است.
2. برو به آدرس: https://myaccount.google.com/apppasswords
3. یک App Password جدید بساز (مثلاً با نام "Accounting App").
4. یک کد ۱۶ رقمی به تو می‌دهد — همین را در مرحله بعد استفاده می‌کنیم (نه رمز عبور همیشگی جیمیلت).

### مرحله ۲: آماده‌سازی کلید SSH برای VPS
اگر از قبل کلید SSH نداری، در Command Prompt ویندوز (یا PowerShell) بزن:
```
ssh-keygen -t rsa -b 4096
```
با Enter زدن پشت سر هم، کلید در مسیری مثل `C:\Users\YourName\.ssh\id_rsa` (خصوصی) و `id_rsa.pub` (عمومی) ساخته می‌شود.
کلید عمومی را به VPS اضافه کن (روی خود VPS، در ترمینال آن):
```
mkdir -p ~/.ssh
echo "محتوای فایل id_rsa.pub را اینجا paste کن" >> ~/.ssh/authorized_keys
mkdir -p /home/backups
```

سپس، برای اینکه برنامه مطمئن شود واقعاً به همان VPS خودت وصل می‌شود (نه یک سرور جعلی روی همان آی‌پی)، باید کلید میزبان VPS را یک‌بار به‌صورت دستی تأیید کنی؛ در همان Command Prompt/PowerShell:
```
ssh-keyscan -p 22 آی‌پی_VPS_تو >> %USERPROFILE%\.ssh\known_hosts
```
(یا به‌جای این دستور، یک‌بار با `ssh root@آی‌پی_VPS_تو` دستی به VPS وصل شو و «yes» را برای تأیید کلید بزن.) بدون این مرحله، آپلود بکاپ با خطای «کلید میزبان ناشناس» رد می‌شود — این یک اقدام امنیتی عمدی است تا جلوی حمله مرد میانی (MITM) روی بکاپ‌های مالی گرفته شود.

### مرحله ۳: ساخت فایل config.json
فایل `server/config.example.json` را کپی کن و به اسم `server/config.json` ذخیره کن، سپس مقادیر را با اطلاعات خودت پر کن:
```json
{
  "email": {
    "enabled": true,
    "sender": "youraddress@gmail.com",
    "app_password": "کد ۱۶ رقمی مرحله ۱",
    "recipient": "youraddress@gmail.com",
    "attach_backup": true
  },
  "vps": {
    "enabled": true,
    "host": "آی‌پی VPS تو",
    "port": 22,
    "username": "root",
    "key_path": "C:\\Users\\YourName\\.ssh\\id_rsa",
    "remote_dir": "/home/backups"
  }
}
```

> ⚠️ فایل `config.json` حاوی اطلاعات حساس است (رمز ایمیل، دسترسی سرور)؛ آن را برای هیچ‌کس نفرست و در جای امن نگه دار.

### مرحله ۴: تست دستی (بدون نیاز به صبر تا ساعت ۱۱ شب)
از داخل برنامه کلاینت، برو به تب "پشتیبان‌گیری" و دکمه "ارسال گزارش شبانه همین الان (تست)" را بزن. نتیجه (موفق یا خطا برای هرکدام از ایمیل و VPS) نمایش داده می‌شود.

## امکانات نسخه فعلی (خلاصه کامل)
- ورود چندکاربره با سطح دسترسی مدیر/کارمند
- کالا با کد/بارکد، برند، دسته‌بندی، قیمت خرید/فروش، موجودی، حداقل موجودی، گردش انبار
- مدیریت مشتری/تامین‌کننده، بدهکار/بستانکار، تسویه حساب، ریز حساب
- خرید، فروش، مرجوعی خرید، مرجوعی فروش، تخفیف، شماره فاکتور خودکار
- صندوق (دریافت/پرداخت/موجودی)
- گزارش فروش روزانه و ماهانه (با نمودار)، سود، موجودی انبار، پرفروش‌ترین کالاها، مشتریان بدهکار
- چاپ فاکتور PDF در چهار فرمت: A4، A5، رسید حرارتی ۸۰mm و ۵۸mm
- خروجی اکسل از لیست کالاها و فاکتورها
- پشتیبان‌گیری خودکار روزانه + بازیابی دستی
- گزارش شبانه به ایمیل + آپلود بکاپ به VPS
- لاگ فعالیت کاربران (چه کسی چه کاری کرد)
- حالت تاریک/روشن
- بارکدخوان: از قبل پشتیبانی می‌شود، چون بارکدخوان‌های معمولی مثل صفحه‌کلید عمل می‌کنند — کافی است حین افزودن/جستجوی کالا، بارکد را روی فیلد "کد/بارکد" اسکن کنید
- چاپگر حرارتی: فایل PDF با اندازه دقیق ۵۸/۸۰ میلی‌متر ساخته می‌شود؛ از پنجره چاپ ویندوز همان چاپگر حرارتی را انتخاب کنید (چون چاپگرهای حرارتی امروزی معمولاً یک درایور استاندارد ویندوزی دارند)

## نکته‌ای درباره بارکدخوان و چاپگر حرارتی
این دو مورد به سخت‌افزار واقعی وابسته‌اند و از راه دور قابل تست نیستند. اگر بعد از نصب با مدل خاص دستگاه‌ خودت مشکلی داشتی (مثلاً چاپگر حرارتی درست چاپ نکرد یا برش کاغذ اشتباه بود)، پیام خطا یا رفتار دقیقش را برایم بفرست تا با توجه به مدل دستگاه، تنظیمات را اصلاح کنم.

## اسکن فاکتور خرید (دو روش: هوش مصنوعی یا رایگان آفلاین) — حالا عکس و PDF هر دو پشتیبانی می‌شوند
از تب «📷 اسکن فاکتور خرید (AI)» می‌توانی عکس یا فایل PDF فاکتور تامین‌کننده را آپلود کنی تا خودکار کالاها استخراج شوند. دو روش داری که هر دو هم‌زمان فعال هستند و هر بار یکی را انتخاب می‌کنی:

### روش ۱: هوش مصنوعی (دقیق‌تر، نیاز به اینترنت + کلید API)
1. یک کلید API از https://console.anthropic.com بگیر (نیاز به کارت پرداخت بین‌المللی دارد؛ هزینه هر تحلیل عکس فقط چند صدم سنت است).
2. فایل `client/config.example.json` را کپی کن به `client/config.json` و بخش `"ai"` را با کلیدت پر کن.
3. از منوی «روش آنالیز» در همان صفحه، گزینه «هوش مصنوعی» را انتخاب کن.
4. عکس یا PDF فاکتور را انتخاب کن — هر دو فرمت مستقیماً پشتیبانی می‌شوند.

### روش ۲: رایگان و آفلاین (Tesseract OCR، بدون نیاز به اینترنت)
دقتش به‌مراتب کمتر از هوش مصنوعی است (مخصوصاً روی خط دستی یا فاکتورهای شلوغ)، ولی کاملاً رایگان است. **این روش دو نصب جداگانه لازم دارد** — پیام خطای "کتابخانه OCR نصب نیست" یعنی هنوز مرحله ۱ (خود برنامه Tesseract) را انجام نداده‌ای؛ فقط pip کافی نیست:

1. **نصب برنامه Tesseract (نه فقط پکیج پایتون):** از این آدرس دانلود و نصب کن: https://github.com/UB-Mannheim/tesseract/wiki (فایل exe نصب، مثل هر برنامه دیگه‌ی ویندوزی).
2. **حین نصب**، در صفحه انتخاب زبان‌های اضافی (Additional language data)، حتماً تیک **Persian** را هم بزن؛ وگرنه فارسی را نمی‌خواند.
3. بعد از نصب، پکیج‌های پایتون را نصب کن (این قسمت را از قبل داری، ولی برای اطمینان):
   ```
   pip install pytesseract pillow pymupdf
   ```
   (`pymupdf` برای خواندن فایل‌های PDF در این روش لازم است.)
4. اگر Tesseract را در مسیر پیش‌فرض نصب کرده باشی (`C:\Program Files\Tesseract-OCR`)، برنامه خودش پیدایش می‌کند؛ در غیر این صورت پیام خطا می‌دهد که مسیر را دستی تنظیم کنی.
5. از منوی «روش آنالیز»، گزینه «رایگان و آفلاین» را انتخاب کن.

در هر دو روش، قبل از ثبت نهایی فاکتور، یک جدول قابل‌ویرایش نشانت داده می‌شود تا کالاها، تعداد و قیمت‌ها را بررسی و در صورت نیاز اصلاح کنی — هیچ‌چیز بدون تأیید صریح تو ثبت نمی‌شود.

## چیزهایی که همچنان می‌توان در آینده اضافه کرد
تمام موارد لیست اولیه (مدیریت پایه، کالا و انبار، مشتری/تامین‌کننده، خرید و فروش، صندوق، گزارش‌ها، امکانات حرفه‌ای شامل بازیابی بکاپ، بدهکاران/بستانکاران و کالاهای پرفروش) اضافه شده است. مواردی که در آینده در صورت نیاز می‌توان اضافه کرد:
- تعریف واحدهای اندازه‌گیری تبدیلی (مثلاً هر قرقره = ۱۰۰ متر) برای سیم و کابل
- امکان صدور فاکتور رسمی مالیاتی (ارزش افزوده) در صورت نیاز قانونی
- برنامه موبایل جداگانه برای دسترسی از بیرون مغازه (فعلاً فقط از طریق ایمیل شبانه قابل مشاهده است)
