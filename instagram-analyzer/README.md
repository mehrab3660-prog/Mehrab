# Instagram AI Analyzer

آنالیز عمیق اکانت اینستاگرام خودتان با استفاده از Claude API برای تحلیل هوشمند (احساسات کامنت‌ها، گزارش عملکرد، تحلیل تصویر پست‌ها).

این پروژه دو روش برای اتصال به اینستاگرام دارد:

## روش ۱ (پیش‌فرض): ورود مستقیم با یوزرنیم/پسورد

از کتابخانه‌ی `instagrapi` استفاده می‌کند که همون پروتکل خصوصی اپ موبایل اینستاگرام رو شبیه‌سازی می‌کنه — نیازی به ساخت اپ در Meta for Developers نیست، فقط یوزرنیم/پسورد می‌خواد.

**⚠️ هشدار مهم قبل از استفاده:**
- این روش **خلاف قوانین استفاده‌ی اینستاگرام (ToS)** است — API رسمی نیست.
- ریسک واقعی **محدود شدن نرخ درخواست، چالش امنیتی (checkpoint)، یا مسدود شدن اکانت** وجود دارد.
- چون رسمی نیست، هر وقت اینستاگرام ساختار داخلی اپش رو عوض کنه ممکنه از کار بیفته.
- فقط با اکانت **خودتان** و با آگاهی کامل از این ریسک‌ها استفاده کنید.
- پسورد شما به‌صورت خام ذخیره **نمی‌شود** — فقط نشست ورود (session) بعد از لاگین موفق در دیتابیس نگه داشته می‌شود. اگر نشست منقضی شود، باید دوباره با یوزرنیم/پسورد وارد شوید.

## روش ۲ (جایگزین، قانونی‌تر): API رسمی متا

اگر می‌خواهید از مسیر رسمی و پایدارتر استفاده کنید (نیازمند ساخت اپ در Meta for Developers — که ممکن است در برخی کشورها به دلیل تحریم در دسترس نباشد)، این روش هم پیاده‌سازی شده و محدودیت‌هایش این‌هاست:

- فقط برای اکانت‌های از نوع **Business یا Creator** که به یک **صفحه‌ی فیسبوک** متصل‌اند کار می‌کند
- صاحب اکانت باید از طریق OAuth دسترسی را تأیید کند

## راه‌اندازی

### ۱. ساخت اپ در Meta for Developers (فقط لازم اگر از روش ۲ استفاده می‌کنید)

اگر فقط از ورود مستقیم (روش ۱) استفاده می‌کنید، از این بخش رد شوید و مستقیم به «۲. تنظیم محیط» بروید.

1. به [developers.facebook.com](https://developers.facebook.com) بروید و یک اپ جدید بسازید (نوع Business).
2. محصول **Instagram Graph API** و **Facebook Login** را به اپ اضافه کنید.
3. در تنظیمات Facebook Login، این آدرس را به عنوان Valid OAuth Redirect URI اضافه کنید:
   `http://localhost:8000/auth/callback` (یا آدرس دامنه‌ی واقعی‌تان)
4. دسترسی‌های (Permissions) زیر را برای اپ درخواست/تأیید کنید:
   - `instagram_basic`
   - `instagram_manage_insights`
   - `instagram_manage_comments`
   - `instagram_manage_messages` (فقط لازم اگر می‌خواهید جواب خودکار دایرکت/کامنت را هم فعال کنید — پایین‌تر توضیح داده شده)
   - `pages_show_list`
   - `pages_read_engagement`
5. تا زمانی که اپ در حالت Development است، فقط کاربران تعریف‌شده به عنوان Developer/Tester روی اپ می‌توانند لاگین کنند. برای استفاده‌ی عمومی باید اپ توسط متا ریویو شود (App Review).

### ۲. تنظیم محیط

```bash
cd instagram-analyzer
python -m venv venv
source venv/bin/activate  # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# اگر فقط روش ۱ (ورود مستقیم) رو استفاده می‌کنید، فقط ANTHROPIC_API_KEY و SESSION_SECRET لازمه.
# برای روش ۲ (API رسمی) مقادیر INSTAGRAM_APP_ID و INSTAGRAM_APP_SECRET رو هم پر کنید.
```

### ۳. اجرا

```bash
uvicorn app.main:app --reload
```

سپس به `http://localhost:8000` بروید:
- **روش ۱ (پیش‌فرض):** یوزرنیم و پسورد اینستاگرامتون رو توی فرم بالای صفحه وارد کنید و «ورود و اتصال» بزنید. اگه اینستاگرام کد تأیید (۲مرحله‌ای یا چالش امنیتی) خواست، یک فیلد کد ظاهر می‌شه که باید کدی که دریافت کردید رو واردش کنید.
- **روش ۲ (اختیاری):** روی «اتصال با API رسمی» بزنید، وارد فیسبوک شوید و اکانت اینستاگرام کسب‌وکارتان را انتخاب کنید.

## معماری

- `app/instagram_private_client.py` — کلاینت ورود مستقیم (instagrapi): لاگین با یوزرنیم/پسورد، مدیریت ۲FA/چالش، پروفایل، پست‌ها، کامنت‌ها
- `app/instagram_client.py` — کلاینت Instagram Graph API رسمی (OAuth، پروفایل، پست‌ها، اینسایت‌ها، کامنت‌ها)
- `app/ai_analysis.py` — لایه‌ی هوش مصنوعی (Claude): تحلیل احساسات کامنت‌ها، تولید گزارش، تحلیل تصویر
- `app/models.py` — مدل‌های دیتابیس (SQLAlchemy / SQLite به‌صورت پیش‌فرض) — هر اکانت `auth_method` مشخصی داره (`private` یا `official`)
- `app/routers/` — اندپوینت‌های FastAPI (`private_auth`, `auth`, `accounts`, `analysis`, `webhooks`)
- `app/routers/webhooks.py` — دریافت رویدادهای دایرکت/کامنت جدید از متا و جواب خودکار با Claude (فقط روش ۲)
- `web/` — داشبورد ساده (HTML/CSS/JS بدون وابستگی خارجی)

## جریان کار

1. **اتصال اکانت** — یا از طریق فرم یوزرنیم/پسورد (`/auth/private/login`)، یا OAuth رسمی (`/auth/login`).
2. **همگام‌سازی داده** (دکمه «به‌روزرسانی داده‌ها») → پست‌ها، اینسایت‌ها (در صورت دسترس بودن) و کامنت‌های جدید گرفته و در دیتابیس ذخیره می‌شوند.
3. **تحلیل هوش‌مصنوعی** (دکمه «تحلیل با هوش‌مصنوعی») → کامنت‌های تحلیل‌نشده امتیازدهی احساسی می‌شوند و یک گزارش کامل فارسی تولید می‌شود.
4. **جواب خودکار دایرکت/کامنت** (اختیاری، فقط روش ۲) → وقتی فعال باشد، هر دایرکت یا کامنت جدید را Claude به‌جای شما جواب می‌دهد — بدون تأیید دستی، به‌صورت کاملاً خودکار.

## راه‌اندازی جواب خودکار دایرکت/کامنت (اختیاری)

این قابلیت فقط با **API رسمی متا** کار می‌کند (نه با روش ورود مستقیم) و نیازمند این مراحل اضافه‌ست:

### ۱. دسترسی‌های اضافه روی اپ متا
علاوه بر دسترسی‌هایی که در بخش «ساخت اپ در Meta for Developers» گفته شد، این دو مورد هم لازم است (اولی از قبل توی لیست بود، فقط مطمئن شوید هر دو تأیید شده‌اند):
- `instagram_manage_comments` (جواب به کامنت)
- `instagram_manage_messages` (جواب به دایرکت)

### ۲. هاست عمومی (Webhook)
متا باید بتواند هر بار که دایرکت/کامنت جدید می‌آید، به برنامه‌ی شما خبر بدهد — یعنی برنامه باید یک آدرس **عمومی و HTTPS** داشته باشد، نه فقط `localhost`. برای تست لوکال می‌توانید از ابزاری مثل [ngrok](https://ngrok.com) استفاده کنید:

```bash
ngrok http 8000
```

آدرسی که ngrok می‌دهد (مثل `https://abcd1234.ngrok-free.app`) را برای مرحله‌ی بعد نگه دارید.

### ۳. ثبت Webhook در داشبورد اپ متا
1. توی داشبورد اپ، بخش **Webhooks** را باز کنید (اگر نبود، از App Settings محصول Webhooks را اضافه کنید)
2. محصول **Instagram** را انتخاب کنید و **Subscribe to this object** بزنید
3. Callback URL: آدرس ngrok + `/webhooks/instagram` (مثلاً `https://abcd1234.ngrok-free.app/webhooks/instagram`)
4. Verify Token: همان مقداری که در `.env` برای `WEBHOOK_VERIFY_TOKEN` گذاشتید
5. فیلدهای (Fields) `comments` و `messages` را Subscribe کنید

### ۴. مقدار `.env`
```
WEBHOOK_VERIFY_TOKEN=یک-رشته‌ی-دلخواه-که-توی-قدم-۳-هم-همینو-وارد-کردید
```

بعد از این تنظیمات، هر دایرکت یا کامنت جدید روی اکانت متصل‌شده (روش ۲) به‌صورت خودکار توسط Claude — با توجه به بیو و موضوع پست‌های اخیر پیج — جواب داده می‌شود. لاگ جواب‌های ارسال‌شده را می‌توانید در بخش «جواب‌های خودکار اخیر» توی داشبورد هر اکانت ببینید.

**⚠️ نکات مهم:**
- چون جواب‌ها کاملاً خودکار و بدون تأیید دستی ارسال می‌شوند، پاسخ نامناسب هوش‌مصنوعی هم به‌همون شکل ارسال می‌شود — این ریسک را بپذیرید.
- اینستاگرام برای پیام‌رسانی خودکار محدودیت «پنجره‌ی ۲۴ ساعته» دارد (فقط تا ۲۴ ساعت بعد از آخرین پیام کاربر می‌توانید آزادانه پیام بفرستید)؛ این پروژه این محدودیت را خودش اعمال نمی‌کند — اگر پیام رد شد، خطای متا در سرور لاگ می‌شود.

## نکات و محدودیت‌ها

### روش ۱ (ورود مستقیم)
- نشست ورود (session) در دیتابیس ذخیره می‌شود، نه پسورد خام. اگر نشست منقضی/باطل شود، باید دوباره با یوزرنیم/پسورد از طریق فرم وارد شوید.
- اینسایت‌های دقیق پست (ایمپرشن، ریچ) فقط برای اکانت‌های Business/Creator و به‌صورت best-effort در دسترسند؛ ممکن است برای اکانت شخصی خالی برگردد.
- ورود مکرر یا sync بیش‌ازحد مکرر می‌تواند باعث فعال شدن چالش امنیتی اینستاگرام یا محدودیت نرخ شود — sync رو با فاصله‌ی معقول (نه هر چند دقیقه) انجام بدید.

### روش ۲ (API رسمی)
- Instagram Graph API نرخ محدودیت (rate limit) دارد؛ برای اکانت‌های با پست/کامنت زیاد ممکن است sync طولانی شود.
- برای دریافت کامنت‌ها نیاز به تأیید دسترسی `instagram_manage_comments` توسط متا دارید.
- توکن‌های بلندمدت حدود ۶۰ روز اعتبار دارند و باید قبل از انقضا رفرش شوند (این پروژه فعلاً رفرش خودکار ندارد).
